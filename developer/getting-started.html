开发环境与源码运行 ​

准备工具 ​

工具项目要求
Git获取仓库和维护变更
Node.js22.12 或以上版本
pnpm9.10.0，与根 package.json 的 packageManager 一致
Ruststable 工具链，包含 Cargo
macOS 编译依赖Xcode 或 Xcode Command Line Tools

仅开发 macOS 桌面应用时，可使用 Command Line Tools。安装方式见 Tauri 官方前置依赖说明。

安装后可检查工具是否可用：

bash
git --version
node --version
pnpm --version
rustc --version
cargo --version
xcode-select -p

获取代码并启动桌面端 ​

bash
git clone https://github.com/skyzfdance/RelayPulse.git
cd RelayPulse
pnpm install --frozen-lockfile
pnpm dev:desktop

命令启动 RelayPulse Dev，同时运行 Vue 前端和真实 Rust 后端。首次启动会下载并编译依赖，耗时取决于网络与机器性能。

出现主窗口后，使用测试站点完成一次探测，确认前端与后端连通。系统托盘、小面板位置、原生材质、通知权限和真实模型请求均需在桌面端验证。

只开发前端页面 ​

bash
pnpm dev:web

主窗口地址为 http://localhost:1421，小面板为 http://localhost:1421/panel。浏览器中的 API 由 frontend/src/mocks/ 处理，适合检查页面、交互和模拟状态；这些结果不代表真实后端调用通过。

前端服务使用固定端口 1421。桌面启动会管理其前端服务，切换运行方式前先停止已有服务，避免占用端口。

启动失败时 ​

  1. 先核对工具版本和终端错误，确认依赖安装成功。
  2. 前端端口被占用时，检查是否还有上一次启动的进程。
  3. Rust 编译失败时，保留完整错误，核对 macOS 编译依赖。
  4. 运行 pnpm info:desktop 获取 Tauri 与系统环境信息。

开发版与正式版使用各自的数据目录和系统权限，具体见构建与环境隔离。

全部根脚本、前端子项目命令、测试过滤、Tauri 参数和文档站命令见开发命令参考。
