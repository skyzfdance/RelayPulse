项目结构与职责 ​

仓库目录 ​

目录职责
frontend/src/Vue 3、TypeScript、Pinia、antdv-next、Tailwind CSS 4 前端
frontend/tests/前端单元、集成、端到端测试和测试支持代码
backend/src/Tauri 桌面宿主、应用编排和产品业务模块
backend/crates/可复用 Rust SDK 库
backend/tests/Rust 单元、集成测试及支持代码
scripts/仓库级启动、打包、架构与 SDK 检查脚本
scripts/tests/桌面环境与启动脚本测试
docs/文档和资源；当前文档站位于 docs/guide/
legacy/frontend/、legacy/backend/本地旧实现归档，已忽略且不参与当前检查

JavaScript 依赖与前端工具配置归属 frontend/；Cargo、Tauri 配置和平台资源归属 backend/。根目录脚本负责协调各项目。

前端调用边界 ​

页面通过 frontend/src/api/ 中的统一接口层调用后端。call-backend.ts 负责调用入口，浏览器开发环境接入 mock；Tauri 环境执行实际命令。后端状态变化通过事件通知前端重新读取快照。

共享纯类型放入 frontend/src/types/，组合式函数放入 composables/，纯工具函数放入 utils/。功能内部使用的内容保留在功能目录内，不创建 frontend/src/shared/。

后端层次 ​

位置职责
backend/src/desktop/托盘、窗口、系统能力与桌面环境接入
backend/src/application/启动恢复、依赖组装、任务编排、快照与跨模块协作
backend/src/modules/configuration/应用配置
backend/src/modules/sites/站点、凭据、模型与请求策略
backend/src/modules/monitoring/正式探测、健康状态和探测历史
backend/src/modules/iq_test/题库、测试任务、历史与输出回放

产品业务保留在宿主模块；公共 SDK 不依赖 Tauri 或宿主产品模块。站点探针策略、请求参数和凭据规则属于 backend/src/modules/sites/，公共 model-client 只处理协议请求与通用 HTTP 校验，不承载 RelayPulse 的产品策略。

站点模型列表、探针、IQ 预检和测试请求都使用已保存或用户输入的 Base URL 与端点原文拼接。协议分页只修改分页查询参数，不调整端点路径。前端预览、后端请求及 JSON/JSONL 记录应对齐同一个请求地址；涉及请求配置变更时，分别验证最终请求和值的脱敏记录。

公共 SDK 依赖 ​

以下为仓库内公共库之间允许的生产依赖，具体约束由 scripts/check-architecture.mjs 检查：

公共库允许依赖的公共库
relaypulse-runtime无
relaypulse-model-clientruntime
relaypulse-storageruntime
relaypulse-diagnosticsruntime
relaypulse-operationsruntime、storage
relaypulse-notificationsstorage、diagnostics

修改公共 API 或模块依赖后，执行架构与 SDK 检查。
