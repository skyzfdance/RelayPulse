## 1. 计划范围

本目录只管理 [RelayPulse MVP 01：桌面壳与 UI](../README.md)。当前阶段先建立真实 Tauri/Rust 壳，再用类型化 mock data source 实现和验收九个定稿 view。

SQLite、CredentialStore、真实模型 API、SSE、TTFT 测量、调度和状态聚合均属于后端阶段。本轮文档完成不代表 UI 已实现、测试已执行或候选已验收。

## 3. 文档权威关系

```text
RelayPulse 项目总方案（完整产品）
  -> MVP 01 桌面壳与 UI
     -> UI 定稿索引 + MVP 01 开发计划
        -> Tauri 壳、React UI、fixture、测试、九图和验收证据

MVP 01 已验收接口
  -> 后端阶段的 TauriRelayPulseDataSource
```

- 项目总方案描述最终探针产品；MVP 01 不应提前实现后端。
- 九张 PNG 是视觉权威来源；原型只用于查看状态和提取 fixture。
- `RelayPulseDataSource` 是 UI 与后端之间的稳定实现边界。
- 实测若证明壳层或 UI 方案不可行，应先更新阶段入口或 ADR，再改实现。

只有冻结候选的 P0/P1、AC-01 至 AC-05、九图 9/9、三平台壳层和范围审查全部通过，阻塞问题清零并完成角色确认后，MVP 01 才可标记已验收。该结论只代表桌面壳与 UI，不代表后端功能完成。
