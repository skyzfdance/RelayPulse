RelayPulse 3.0.2 发布说明 ​

发布日期：2026 年 11 月 13 日

3.0.2 更新站点探针策略、IQ 测试请求配置和请求记录，让界面预览、实际请求及落盘快照更一致。

新增与调整 ​

  • 站点默认策略和模型策略使用一致的请求头、请求体编辑器，支持字段启停、JSON 粘贴和请求预览。
  • 模型请求策略分为继承站点默认、独立策略和自定义策略。自定义探针端点可单独配置；关闭时保留站点默认端点。
  • 新建站点时，标准协议会预填可编辑的模型列表及探测端点；自定义 HTTP 的端点留空。创建站点时默认不显示在小面板中。
  • 模型发现失败时仍保存站点，支持之后修改模型列表端点、重试同步或手动添加模型。模型目录分页继续使用上游游标。
  • IQ 测试参与者可以独立配置请求头和请求体，并保存自己的配置快照。推理档位统一为 low、medium、high、xhigh、max 和“自定义”。自定义 HTTP 的档位仅作为标记，Body 由用户填写。
  • 探针和 IQ 请求预览、请求快照及 JSONL 记录统一展示实际请求地址，并对访问凭据脱敏。
  • 改进流式响应内容解析和请求记录，区分输出内容、响应字节数与服务商返回的 Token 用量。

地址填写提醒 ​

模型发现、探针和 IQ 请求地址按 Base URL + 端点 原文拼接。程序不会补版本路径或斜杠，也不会纠正输入。添加或编辑站点后，请检查地址预览并按服务商文档填写完整路径。

兼容与验证 ​

服务商是否接受某个请求字段或推理档位，由服务商和模型决定。需要额外请求头或请求体字段时，请自行在对应策略中填写，并通过请求预览与预检验证。

阅读使用者手册查看站点、探针、IQ 测试和请求记录的操作说明；开发者可阅读开发者文档。
