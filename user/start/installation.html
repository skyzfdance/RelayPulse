安装与首次启动 ​

本手册面向 macOS 桌面端。开始前准备好模型服务商提供的服务地址、接口协议、API Key，以及至少一个可用的模型名称。

下载应用 ​

前往 RelayPulse 发布页，查看版本说明和附件。

前往 RelayPulse Releases，查看公开版本说明与附件。以页面实际提供的下载文件为准；GitHub 自动生成的 Source code 压缩包是源码，不是桌面安装包。

  • 发布附件中有适合你的 Mac 的安装包时，按附件说明安装。若为 .dmg，打开后将应用拖到“应用程序”文件夹。
  • 若某个版本只有 GitHub 自动生成的 Source code 压缩包，它们是源代码，不能直接作为桌面应用安装。
  • 若同时提供 Apple Silicon 和 Intel 安装包，在苹果菜单“关于本机”中确认芯片类型后选择对应附件。

下载后先阅读该版本说明，确认是否有升级或数据迁移提示。应用首次打开遇到系统提示时，根据 macOS 显示的具体原因处理；无法判断时保留提示内容，向项目反馈。

第一次打开 ​

  1. 打开 RelayPulse，等待启动检查完成。
  2. 新安装且没有旧数据时，会进入主窗口。“配置 → 站点管理”显示“还没有站点”。
  3. 若显示“需要迁移旧版本数据”，按版本升级说明操作。
  4. 完成第一次探测，确认站点、模型和凭据可用。

RelayPulse 的主窗口用于配置；状态栏图标用于打开小面板。点击小面板的“设置”可以重新打开主窗口。
