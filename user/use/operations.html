本页目录

操作记录 ​

入口：运行 → 操作记录。操作记录用于了解“谁在什么时候执行了什么，以及是否完成”。单次模型请求的技术细节在探测记录中查看。

筛选操作 ​

可以按以下条件组合查找：

  • 时间范围：选择开始、结束日期，或使用最近一周、最近 15 天、最近 30 天等快捷范围。
  • 操作来源：系统或用户。
  • 执行结果：成功、失败、已取消、受阻。
  • 操作动作：按页面提供的动作分类筛选。

筛选支持多选。表格展示来源、动作、操作概要、结果和时间，支持分页。

阅读详情 ​

打开某一行的详情，可以看到时间、来源、执行者、操作对象，以及这次事件保存的内容。

配置变更可能展示修改前后值；创建或删除事件可能展示当时的快照；运行类事件可能展示执行过程或关联记录入口。详情里的名称和值反映事件发生时的内容。

敏感字段以“已配置”“已更换”“已隐藏”等形式展示，不会直接显示 API Key。

从操作记录追踪失败 ​

  1. 按问题发生时间缩小范围。
  2. 选择“失败”或“受阻”，检查动作和操作对象。
  3. 打开详情，阅读失败原因和执行结果。
  4. 若有“关联探测记录”入口，继续查看对应的正式请求。

“受阻”表示该操作未能按要求继续，例如当前站点已被其他任务占用；“已取消”表示流程被取消。它们都不能直接等同于模型服务故障。

某次操作没有生成正式探测记录时，详情会说明没有对应记录。配置草稿试探、页面操作和设置变更都可能出现这种情况。
