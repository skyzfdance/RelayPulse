托盘小面板 ​

macOS 状态栏中的 RelayPulse 图标是日常查看状态的入口。主窗口关闭后，应用仍可按设置在后台工作。

打开和关闭面板 ​

  • 单击状态栏图标打开或收起小面板。
  • 点击面板外部收起面板。
  • 点击面板右上角“设置”打开通用设置。
  • 点击“查看全部”进入主窗口的站点管理。
  • 右键状态栏图标，可以选择“打开状态面板”或“退出 RelayPulse”。

退出应用会停止后台任务；关闭主窗口后的行为由通用设置控制。

查看模型状态和耗时 ​

面板按站点分组，展示模型名称、所属站点、当前健康状态，以及“首 Token / 总耗时”。最多显示 3 个模型；底部“显示 x/y 个模型”表示当前可见数量与全部数量。

模型缺少某个耗时数据时显示 —。例如 — / 2.10 s 表示有总耗时数据，但没有首 Token 数据。状态判定和计时口径见探针说明。

没有正式结果时显示“等待探测”；达到健康判定阈值前可能显示“待确认”。可以在“运行 → 探测记录”核对具体请求结果。

立即探测 ​

点击右上角刷新图标“立即探测”，会发起正式探测，而不只是重新读取界面数据，因此可能产生 API 用量。正在探测时，该按钮会显示忙碌状态。

底部的“最近完成”表示最近一轮探测完成时间；“下次”表示已安排的周期探测时间。显示“未启用周期探测”时，检查自动探测条件。

图标颜色代表什么 ​

状态栏图标显示蓝色，表示当前存在已启用、可参与面板展示的站点和模型。模型是否健康，要看面板内每一行的状态。

需要隐藏状态栏图标时，在“配置 → 通用设置”关闭“显示状态栏图标”。该开关只控制图标，后台探测仍按其自身条件运行。
