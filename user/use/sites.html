站点与模型 ​

入口：配置 → 站点管理。左侧选择站点，右侧编辑该站点的连接信息、默认策略和模型。

选择接口协议 ​

添加站点时，选择与服务商 API 匹配的接口协议。常规协议会把常用端点预填到可编辑字段中；切换协议时会同步更新端点。自定义 HTTP 没有统一的路径，按服务商文档填写。

协议模型列表端点默认值探测端点默认值
OpenAI 兼容协议/models/chat/completions
OpenAI Responses/models/responses
Anthropic 协议/models/messages
自定义 HTTP留空留空

这些只是界面默认值，不会根据 Base URL 自动添加版本路径。你可以在添加窗口里修改端点；创建后也可以在站点高级设置中调整。模型列表端点留空时跳过远端模型发现，之后可以手动添加模型。

Base URL 与端点怎样填写 ​

请求地址严格按输入原文拼接：Base URL + 端点。程序不会添加、删除或纠正斜杠，也不会补 /v1、解析相对路径或替换地址。预览、探测、模型获取、IQ 测试和请求记录遵循相同规则。

Base URL端点请求地址
https://api.example.com/modelshttps://api.example.com/models
https://api.example.com/v1/responseshttps://api.example.com/v1/responses
https://aitogether.site/usagev1/reshttps://aitogether.site/usagev1/res

填写时请对照预览确认最终地址。如果服务商要求路径分隔符或版本路径，请在 Base URL 或端点中自行填写。

模型列表读取失败不会阻止保存站点。检查端点、凭据和服务商要求后，可以在高级设置中修改模型列表端点并同步模型；也可以手动添加模型。

修改站点信息和 API Key ​

  1. 在左侧选中站点。
  2. 修改名称、协议、Base URL 或访问凭据。
  3. 点击“保存变更”。

已有凭据时，访问凭据输入框留空会保留原值；输入新值并保存会替换凭据。界面显示“已配置凭据”时，不会回显原 API Key。

基本信息有未保存更改时，模型与探针操作会暂时禁用。先保存变更，再打开高级设置或操作模型。

同步或手动添加模型 ​

同步模型用于重新读取服务商目录。模型列表支持服务端游标分页；分页参数只用于后续页面请求，不会改写 Base URL 或端点。出现确认窗口时，检查将新增和移除的模型，再点击“确认同步”。从远端目录消失的模型及其独立设置可能被删除。

添加模型用于补充已知的完整模型标识。新增模型默认继承站点探针策略，随后按需开启模型探测。

模型行中的策略列会显示“继承站点默认”“独立策略”或“自定义策略”，具体配置见探针配置。

启停与排序 ​

  • 新建站点默认在小面板中隐藏；站点开关控制小面板显示，并影响自动周期探测。
  • 模型探测开关控制该模型是否参与常规批量和自动探测。
  • 单模型“立即探测”是显式手动操作，可以用于验证该模型；批量操作只选择已启用模型。
  • 拖动左侧站点的排序手柄调整顺序。

站点顺序会影响优先级和小面板的显示顺序。RelayPulse 是探测工具，不会替其他应用自动切换 API 请求线路。

删除站点或模型 ​

删除站点会同时删除该站点下的模型和独立设置；删除模型也会失去对应的模型独立配置。操作前先核对确认框里的对象。

同一站点正在同步、探测或保存时，相关按钮可能暂时不可用，等待当前任务结束后再操作。
